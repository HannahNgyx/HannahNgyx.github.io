# What moves

Every animation on the site lives in its section's `enhance/` folder (house rule L-2) and gets a row here, added by the ticket that adds it. Rules and house pace are in the kit's `house-rules` (M-1 to M-10). With enhance off nothing moves; each row's base column says what shows instead.

| Thing | Where | Trigger → what happens → how much | Reduced motion | Enhance off |
|---|---|---|---|---|
| Hero photo reveal (HERO-11, #9) | `src/pages/home/hero/enhance/hero.css`, `.hero__figure[data-photo-reveal]` | Hover on the figure box → `.hero__photo` opacity 0 → 1, `.hero__outline` and `.hero__hint` opacity 1 → 0 → cross-fade, `--dur-quick` (200ms) `--ease-state` (`ease`), opacity only, no movement. Desktop only (figure is `display: none` without a fine hover pointer or at ≤30rem). Not focusable, so no focus path yet (follow-up). | Same end states, switched instantly (`transition: none`). | The same swap, at once (HERO-7). |
| Narrow nav menu open/close (NAV-12, #10) | `src/shared/nav/enhance/nav.css`, narrow block: `.nav__menu`, open on `.nav[data-open]` | Menu button (and close on Escape / link / outside click) → `.nav__menu` opacity 0 → 1 and `translateY(-4px)` (`-var(--space-1)`) → `none`, reversed on close → `--dur-quick` (200ms) `--ease-state` (`ease`). Closed state is `visibility: hidden` + `pointer-events: none` (base); on close `visibility` flips after a 200ms delay so the fade shows, pointer-events drop at once. Narrow (≤30rem) only; at 768 and up the menu is a static row with no transition. | Same end states, switched instantly (`transition: none`). | Opens and closes at once (NAV-6). |
| Nav cursor spot (NAV-9, #12) | `src/shared/nav/enhance/NavSpot.jsx` (layers and effect, through the nav's Slot), `src/shared/nav/enhance/nav.css` (`@property --spot-r`, `.nav` transition) | Mouse over `.nav` → passive `pointerenter/move/leave` on the nav set `--spot-x/--spot-y` (`clientX/Y − nav rect`, px) directly on the element, rAF-throttled, no easing on position; enter places it then adds `data-spot`, leave removes it → `--spot-r` 0 ↔ `--nav-spot-r` (24px radius) over `--dur-quick` (200ms) `--ease-state` (`ease`). Only while `(hover: hover) and (pointer: fine) and (width > 30rem)` matches (re-evaluated on `change`); `pointerType !== "mouse"` ignored. The radius isn't a transform: a mask circle can't be scaled without scaling the text, so `--spot-r` is a registered `<length>` and transitioned (repaint of two masked layers, no layout; NAV-9's exception to M-1). | Still follows the pointer (direct manipulation); appears/disappears instantly (`transition: none` on `.nav`). | No spot layers rendered. |
| Worked-at rainbow (HERO-9, #12) | `src/pages/home/hero/enhance/hero.css`, `.hero__company[data-rainbow]` inside the `@supports` block | `:hover` / `:focus-visible` on a company link → `.hero__company-rainbow` opacity 0 → 1, `.hero__company-name` 1 → 0, reversed on leave/blur → cross-fade `--dur-quick` (200ms) `--ease-state` (`ease`), opacity only. All widths. | Same end states, switched instantly (`transition: none`). | No rainbow copy; the link stays `--color-text`, underlined (HERO-12). |
| Project video playback (VIDEO-5, #11) | `src/pages/home/hero/enhance/useAutoplayVideos.js`, run by `enhance/VideoAutoplay.jsx` through the cards' Slot on the `.videos` list | Every `video[data-autoplay]` (muted, loop, playsinline, no `autoplay` attribute, no controls) → `play()` while it intersects the viewport (`IntersectionObserver`, threshold 0) and reduced motion is off; `pause()` once it is fully off screen → native speed, endless loop, no CSS motion. `src` gets `#t=0.1` so a paused video seeks and paints a frame even with `preload="metadata"`. `play()` rejections are swallowed. Re-evaluated on the reduced-motion `change` event; cleanup removes the listener, disconnects the observer and pauses all. Hidden tabs are left to the browser (it already throttles background media). | Never starts: paused at 0.1s with that frame shown. Switching to reduce live pauses on the current frame; switching back resumes the on-screen ones. | Never starts: the 0.1s frame (VIDEO-8). |
| Video card float (VIDEO-6, #13) | `src/pages/home/hero/enhance/hero.css`, `.video-card[data-float]`, `@keyframes video-card-float` | Self-running from load → `translate` 0 → `0 -var(--float-y)` (6px up) and back, `--dur-float` (6s) per leg, `ease-in-out`, `infinite alternate`; delays 0 / −1.5s / −3s / −4.5s for cards 1–4 so they never move together. `translate` only: the tilt (`rotate`, VIDEO-3) and `transform` are untouched and compose with it. Above 64rem only (cards are `display: none` below, so nothing runs). Pure CSS: no off-screen pause, as browsers throttle CSS animations in hidden tabs and it's compositor-only. | `animation: none`: cards sit still at their VIDEO-2 positions. | Still, at their VIDEO-2 positions. |
| Video card expand (VIDEO-7, #13) | `src/pages/home/hero/enhance/hero.css`, `.video-card[data-float]:hover` (inside `(hover: hover) and (pointer: fine)`) and `:focus-visible` (any device) | Hover or keyboard focus on a card → `scale` 1 → `--scale-hover` (1.06), back on leave/blur → `--dur-quick` (200ms) `--ease-state` (`ease`). `scale` only; composes with the float and the tilt, and the GLOBAL-5 focus ring tilts and scales with the card. | Same end state, switched instantly (`transition: none`). | No scale. |

## Motion tokens
Values on `:root` in `src/shared/tokens.css`. Defaults for anything without a token yet are the kit's house pace (M-10).

| Token | Value | Use |
|---|---|---|
| `--dur-quick` | `200ms` | hover and state changes (hero photo reveal, narrow nav menu, nav spot radius, worked-at rainbow, video card expand) |
| `--ease-state` | `ease` | state changes (hero photo reveal, narrow nav menu, nav spot radius, worked-at rainbow, video card expand) |
| `--dur-float` | `6s` | one leg (up or down) of the video cards' idle float, with `ease-in-out` `alternate infinite` |
| `--float-y` | `6px` | how far the video cards float up |
| `--scale-hover` | `1.06` | video card size on hover / focus |
